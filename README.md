# Baylat Properties - Multi-Tenant Real Estate Platform

🚀 **Live Web Application:** [https://baylatproperties.ng](https://baylatproperties.ng)

---

## 📌 Project Overview
Baylat Properties is a web application designed for real estate agencies and property listings. It streamlines property management, search filtering, user inquiries, and listing administrative workflows.

---

## 🛠️ Tech Stack
* **Frontend:** React, Tailwind CSS, Vite
* **Backend:** Node.js, Express.js, REST APIs
* **Database & Hosting:** MongoDB, Vercel / Domain Hosting

---

## ✨ Key Features
* 🏠 **Property Listings:** Dynamic display of residential and commercial properties.
* 🔍 **Advanced Search & Filtering:** Filter properties by location, type, and status.
* 📱 **Responsive UI:** Fully optimized layout for mobile, tablet, and desktop screens.
* 📧 **Lead Management:** Integrated inquiry routing for prospective buyers and renters.
